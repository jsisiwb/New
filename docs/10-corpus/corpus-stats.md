(`corpus.chapters`, imported by `corpus:import`, ADR-0082). Every number is measured with the same code the
Korean lint applies to drafts (`chapterMetrics` → `lintKoreanWebnovel` over `lang/ko@6` lists, one paragraph per
line), so a threshold calibrated here means the same thing on a pipeline draft (C4).

Only the two Korean books carry the operator's voice. The translation is stored (so the database mirrors the
repository and the decision is visible) but excluded from statistics, calibration, exemplars, contrast pairs,
the gold set and every annotation, because feeding it to a Korean prompt would put English into a Korean
input (NO-TRANSLATION-001, rule 3).

**Reading the tables.** `talk_share` = dialogue (curly or straight quotes) + 속마음 (‘…’) as a share of
characters; `pronoun_per_1k` = 그/그녀 + particle per 1,000자; `translation_weighted_per_1k` = the layer's
weighted 번역투 markers per 1,000자; `ending_*` = shares of narration sentences by final ending (past -었다,
present -ㄴ다, other -다, noun/fragment endings, dangling connectives); `status_window_lines` = lines that are a
bracketed block (`[…]`, `<…>`), which in book 1 are spirit voices and notes, not a 상태창.
