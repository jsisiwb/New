# ADR-0142: Let structural repairs redesign the scene's causal path

- **Status:** Accepted
- **Date:** 2026-09-27
- **Deciders:** operator request for permanent repetition and pacing fixes
- **Relates to:** ADR-0138, ADR-0140

## Context

A live structural rewrite changed a dust complaint to criticism of a decorative sword while retaining the same threat, indifference and angry reaction. Its instruction required rewriting from the same scene plan, even though that plan could encode the repeated mechanism. The contract's required outcomes and the plan's proposed tactics were not distinguished.

## Decision

For the existing checked scene-rewrite path, identify the original scene plan as revisable planning. Keep accepted history, reveal restrictions, the chapter contract, required outcomes and unchanged draft boundaries authoritative. Permit changes to local tactics, reaction order, humor and costs when needed to repair the stated finding. A repetition repair must change the causal interaction; swapping nouns or adjectives is insufficient.

Replace the contradictory instruction to preserve the same scene plan on this path. Preserve legacy input wording when rewrite checks are disabled. The rewrite is still a new unaccepted manuscript version, subject to the same replacement ranges, length limits, regression checks and approval gates. No planner artifact, contract or accepted history is rewritten.

## Consequences

The rewriter can address a structural cause in the proposed plan without treating a required contract event as optional. This guidance does not guarantee a better scene; rejected candidates remain quarantined. Tests cover the actual checked rewrite request and legacy compatibility.
